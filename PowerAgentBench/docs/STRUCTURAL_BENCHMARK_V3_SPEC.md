# 结构分层Benchmark v3：离线认证规范

本轮实现B0–B4，不改变现有I/V/R八组，也不执行B5–B7。

动作使用整数四元组(-6..6)^4，乘0.25 MW，全集28561。均匀U含零共13，最多单个非零S共49，零/满功率C共81，去重并集131。按以下顺序互斥分类：

| 类别 | 证据 |
|---|---|
| S1 | U有成功动作 |
| S2 | U全失败，S有成功动作 |
| S3 | U和S全失败，C有成功动作 |
| S4 | 三族131动作全失败，且存在独立回放成功的非模板witness |

严格认证要求全部131项有可判读、收敛的数值结果；未评价、异常、非收敛均不作排除证据。所有入选类别均要求独立成功重放，保存全部覆盖计数、动作顺序、状态、源/环境/solver身份。`search_unresolved`不是物理不可行。

S4只证明当前离散网格/冻结数值协议内所有可行解超出三个简单族；不证明LLM更难、不证明必须混合符号或四台都用中间功率。S1保留同向满功率标记。v2公开计数迁移检查应为19/4/1/0，不重新评分旧Pilot。

静态校正的每次方案从同一冻结快照出发；Recovery是失败方案重规划，非真实电网物理回滚。无SOC/无功/多时段/动态安全主张。I0/I1不声称信息等价，V/R不声称同计算机会下的纯反馈效应。

生成与资源闸门见[V3_GENERATION_PROTOCOL.md](V3_GENERATION_PROTOCOL.md)。构造PF不计在线Agent成本；四类配额是合成诊断分布，不代表自然频率。真实产出与未完成部分以[V3_OFFLINE_ACCEPTANCE.md](V3_OFFLINE_ACCEPTANCE.md)为准。
